## 🚀 How to Use

### For Students
1. Download `Shree-Shetty-Precalc-Tutor-1.0.dmg`
2. Double-click to open
3. Drag app to Applications
4. Launch from Applications
5. Start learning! 📚

### For Teachers/Admins
1. See `dist/DISTRIBUTION_CHECKLIST.txt` for classroom deployment
2. Send DMG to students (1.1 MB via email)
3. Or AirDrop `Shree Shetty's Precalc Tutor.app`
4. Each user gets separate progress (automatic)

### For Developers
1. Read `Shree-Shetty-Precalc-Tutor-COMPLETE-SPEC-v1.0.md` (Sections 1-16, 27-28)
2. Modify `highschool-precalculus-tutor/src/`
3. Run: `npm run build`
4. Update app bundle and create new DMG
5. See spec Section 28.5 for rebuild instructions
